# DungeonRPG — 36 transparent single-frame monster references

These files were extracted from the concept atlas as **design references**, not game-ready animation sheets.

- 27 enemy tier reference images (9 families x Tier 1/2/3) at 128 x 128 PNG RGBA.
- 3 boss reference images at 192 x 192 PNG RGBA.
- 6 unique boss-minion reference PNGs at 128 x 128 PNG RGBA.
- For each family, animate Tier 1 first and use it as the exact silhouette reference for Tiers 2 and 3.
- Production animation requires separate 8-column x 10-row spritesheets (ranged monsters 11 rows; bosses 192 px cells).
- Existing concept layout may leave some background glows or stray cut-off components; review individual previews.
